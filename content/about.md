This is the Hugo code I use to generate the HTML files of my blog. A
DevOps/SysAdmin blog about web and network technology stacks, also provides
tutorials and original writing of the author. This blog also covers exciting
news in science and technology.

## Powered by

[Hugo](https://gohugo.io/) is a general-purpose website framework. Technically
speaking, Hugo is a static site generator. Unlike systems that dynamically
build a page with each visitor request, Hugo builds pages when you create or
update your content. Since websites are viewed far more often than they are
edited, Hugo is designed to provide an optimal viewing experience for your
website’s end users and an ideal writing experience for website authors.

[Ananke](https://github.com/theNewDynamic/gohugo-theme-ananke) is a theme for
Hugo, a static site generator. It is a responsive theme with a clean design and
a focus on content. It is designed to be easy to use and customize, making it a
great choice for anyone looking to create a personal blog or website.
